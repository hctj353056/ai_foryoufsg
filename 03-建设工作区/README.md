# 建设工作区

> 本目录用于记录蜉熵阁基础建设过程中的路线图、协作导航、待决议事项与参与者之间的工作同步。
>
> **目录说明，不是正式规范，不创设成员义务、治理权或制度决策权。** 各文件应以自身标注的版本和状态为准。

## 当前导航

| 文件 | 用途 | 状态 |
|---|---|---|
| [决议待办](./00-决议待办.md) | 登记尚待讨论、调查或创建者确认的事项 | 工作记录，非正式规范 |
| [基础建设路线图](./01-基础建设路线图.md) | 说明当前建设目标、优先级与阶段安排 | 工作计划，非正式规范 |
| [会话锚点与协作流程](./02-会话锚点与协作流程.md) | 帮助新会话恢复项目状态与工作上下文 | 工作流程锚点，非正式规范 |
| [认知同步](./认知同步/) | 保存 ChatGPT、灵镜及其他参与者经授权提交的背景同步、独立意见与交叉评审 | 按各文件自身状态为准 |

## 建议阅读顺序

开始新的建设会话时，先阅读：

1. [会话锚点与协作流程](./02-会话锚点与协作流程.md)
2. [决议待办](./00-决议待办.md)
3. [基础建设路线图](./01-基础建设路线图.md)
4. 本次任务涉及的具体文件及必要历史材料

不要仅凭旧会话摘要或模型记忆推断仓库当前状态；涉及具体任务时，应重新核对相关文件。

## 状态与权限提醒

- 工作区文件用于导航、记录、讨论和交接，不因存放于此目录而自动成为正式规范。
- 提案、意见、工作计划、决议与现行规范应保持清晰区分。
- GitHub 写入权限、PR 审查动作和合并权限，不自动构成制度批准权或思想权威。
- 尚未解决的问题继续保留在决议待办中；未获授权的事项不因工作推进而自动获得批准。
