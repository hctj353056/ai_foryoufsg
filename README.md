# 蜉熵阁指引与规范库

这里存放蜉熵阁的根本规范、基本制度、专项条例、实施办法、技术标准和历史记录，供创建者、传承者、成员、协作者及获授权的 AI 阅读与使用。

本仓库正在从原有的指引文件库，逐步建设为一套分层、分类、可修订、可追溯的规范体系。

当前实际参与成员为创建者本人及其确认参与的若干 AI。现阶段先建立基础框架，再邀请其他 AI 作为咨询参与者提出意见，经过核查和讨论后持续修订。

## 从这里开始

第一次进入本仓库，请按顺序阅读：

1. [规范体系总目录](./00-目录.md)：了解整体结构和文件位置。
2. [根本章程目录](./01-根本章程/README.md)：了解根本规范。
3. [蜉熵阁根本章程（讨论稿）](./01-根本章程/01-蜉熵阁根本章程（讨论稿）.md)：了解当前提出的根本原则。注意：该文件尚未正式通过，不具有现行规范效力。
4. [品牌手册修订指引](./01-修订指引/01-品牌手册修订指引.md)：开始品牌手册修订前阅读。

## 当前目录

- `03-建设工作区/`：基础建设路线图与决议待办。该目录记录建设过程，不属于正式规范。

- `01-根本章程/`：根本性规范及其说明。
- `01-修订指引/`：现有品牌手册修订指引。
- `旧归档/2026-04-21/`：原仓库中的旧章程、成员档案和说明文件，原样保留，仅供查阅。

后续将根据制度建设进度，逐步建立基本制度、专项条例、实施办法、技术标准、执行检查和修订记录等目录。

## 使用约定

- 文件必须标明版本和状态，区分讨论稿与现行有效规范。
- 旧归档中的文件只代表历史记录，不自动代表当前规则。
- 下位文件不得擅自改变上位规范的含义。
- 未经确认的建议，不得写成已经确定的规则。
- 修改正式文件前，先阅读适用的规范和指引。
- 修改完成后，检查文件、目录、链接和修订记录。
- 只有实际写入并核对成功后，才能说明修改已经完成。

## 重要说明

本仓库中的内部规范不能取代现实法律法规，也不能自动约束未自愿接受这些规则的外部主体。
