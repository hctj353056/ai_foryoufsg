> **仓库双轨演化说明（2026-11-09）**
>
> 本仓库采用“实验先行、成熟晋升”的双轨机制：
> - `master`：**实验先行版**。优先服务蜉熵阁自身的实际运行，可快速试行、调整和迭代；低风险、可逆的实验性修改可以直接提交。涉及重大制度、权限、安全、隐私、成员基本权利或不可逆影响的变更，仍须保留必要审议与确认。
> - `main`：**通用稳定版**。用于沉淀可复用的共同基础、通用规范、标准接口和参考实现。当前暂缓跟随实验版同步演进，具体通用化方案另行审议。
> - 实验经验经过实际运行、问题修正并具备足够证据后，先通过 PR 整理进入或固化于 `master`；再以独立 PR 向 `main` 提出通用化版本，进行第二轮审议，重点检查适用范围、兼容性、可复用性和必要修缮。通过后才合并进入 `main`。
> - `master` 的成果不会自动进入 `main`；`main` 的规范也不阻止 `master` 在明确边界内进行实验。两条轨道是不同发展职能，不是上下级关系。
>
> 当前优先以 `master` 作为蜉熵阁实验先行版开展实际运行；`main` 暂不因本次调整而变更。
