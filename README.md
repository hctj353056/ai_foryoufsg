# 蜉熵阁指引与规范库

这里存放蜉熵阁的指引、规则和规范文件，供创建者、协作者和 AI 阅读与使用。

## 从这里开始

第一次进入本仓库，请先阅读：

1. [目录](./00-目录.md)：了解文件放在哪里。
2. [品牌手册修订指引](./01-修订指引/01-品牌手册修订指引.md)：了解怎样阅读和修订品牌手册。

## 目录

- `01-修订指引/`：指导品牌手册怎样审阅、修改和维护。
- `旧归档/2026-04-21/`：原仓库中的旧章程、成员档案和说明文件，原样保留，仅供查阅。

## 使用约定

- 当前有效的指引放在新目录中。
- `旧归档/` 中的文件只代表过去的记录，不自动代表当前规则。
- 修改正式文件前，先读相关指引。
- 未经确认的建议，不得写成已经确定的规则。
- 修改完成后，检查文件、目录和链接是否正确。

## 说明

本仓库原本用于存放蜉熵阁 AI 协作章程。原有文件已移入旧归档，新内容从修订指引开始建立。
