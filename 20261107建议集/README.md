# 20261107 建议集

本目录存放 2026-11-07 这一轮对品牌手册提出的修改建议。

## 这是什么

建议，不是规则。

本目录中的文件状态一律为「修改建议」。在创建者逐条确认之前，其中任何一条都不构成规范，不得当作已经确定的内容执行。

依据：《品牌手册修订指引》3.3（把不同状态分清楚）、《蜉熵阁根本章程（讨论稿）》第二十四条（规范状态）。

## 建议针对什么

针对两份品牌手册：

- 《蜉熵阁·品牌手册》
- 《蜉蝣子·品牌手册》

这两份文件目前**尚未进入本仓库**。建议中的条目只有在手册正式入库、并经确认采纳后，才会成为手册条款。

## 怎么处理这些建议

每条建议可以整体采纳、整体退回，或只采纳一部分。

处理方式：

1. 逐条判断。
2. 采纳的写入手册，并把手册中对应的「⚠ 这一节是建议」标记去掉。
3. 退回的删除，不在手册中保留痕迹。
4. 处理后在本目录追加处理记录，说明哪些采纳、哪些未采纳及理由。
